# Repository Instructions

Keep all repository content in English.

Maintain a shared source of truth for working methods. Keep host-specific paths and serialization in adapters. Never imply that a preview installs files or that configuration generation proves live compatibility.

Prefer small functions, precise names, top-level imports, strict types, and validation at boundaries. Preserve unrelated user changes.

Run npm run check after code or content changes. Update documentation when supported behavior changes. Keep credentials and local runtime state out of version control.
