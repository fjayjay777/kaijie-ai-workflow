# Deliver a Feature

Use this workflow when the user asks to implement a feature or explicitly requests pflow-deliver-feature.

1. Read references/pflow-plan-change.md and define the change and its acceptance criteria.
2. Read references/pflow-implement-change.md and implement the authorized change.
3. Read references/pflow-review-change.md and review the resulting diff.
4. Address actionable findings and run the relevant verification.
5. Report the result, files changed, checks actually run, and unresolved limitations.

Ask a focused question when missing information changes the acceptance criteria. Continue independent authorized work while awaiting an answer. Follow project instructions and the current user's authorization.

If verification fails, return to implementation. After two attempts with the same unresolved failure, report the evidence and the missing information or dependency instead of looping indefinitely.

Use conversation output by default. Save artifacts only when requested or required by the project. This is an instruction workflow, not a durable execution engine.
